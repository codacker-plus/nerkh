# نرخ لحظه‌ای

اپ اندروید + ویجت صفحه اصلی برای قیمت دلار، یورو، تتر، طلا، سکه و انس.
منبع: فید زنده tgju.org (قیمت‌ها به تومان، انس به دلار).

## ساخت APK (بدون اندروید استودیو)

```bash
cd nerkh
git init
git add .
git commit -m "init"
git branch -M main
git remote add origin git@github.com:codacker-plus/nerkh.git
git push -u origin main
```

بعد:
1. تو گیت‌هاب برو تب **Actions** و صبر کن بیلد سبز بشه (حدود ۵ دقیقه).
2. برو بخش **Releases** و فایل `nerkh.apk` رو با گوشی دانلود و نصب کن.
3. صفحه اصلی گوشی رو نگه دار ← ویجت‌ها ← «نرخ لحظه‌ای».

هر بار کد رو push کنی، یه APK جدید ساخته می‌شه و روی نسخه قبلی نصب می‌شه.

## بروزرسانی قیمت‌ها

- داخل اپ: هر ۳۰ ثانیه خودکار.
- ویجت: هر ۱۵ دقیقه خودکار (حداقلی که اندروید اجازه می‌ده). برای بروزرسانی فوری، دکمه ⟳ روی ویجت رو بزن.

## تغییر آیتم‌ها

فایل `app/src/main/java/ir/h3xnull/nerkh/PriceRepo.kt` ← لیست `WIDGET_ITEMS` (۶ آیتم ویجت) و `ALL_ITEMS` (همه آیتم‌های اپ).
